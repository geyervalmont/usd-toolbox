# Static model conformance fixtures

`panels.usda` and `checker.png` are original synthetic fixtures authored for this
repository under its project licence. They contain two adjoining textured panels
with a UV seam, two materials, a material face subset, nested translations and
millimetre units. They contain no third-party model data.

The scene's world bounds are `(750, 450, -250)` to `(1750, 450, 250)` in
millimetres. `scripts/validate_model.py` checks those values using the OpenUSD
reference runtime without consulting the toolbox's embedded manifest.

`desk.usda` is an original seven-part desk (1.2 × 0.75 × 0.6 m), with two
materials, nested transforms and indexed UVs. Regenerate it with
`scripts/generate_desk_fixture.py` using OpenUSD 26.8.

`transforms.usda` and `transforms-reference.json` are original conformance data
generated by `scripts/generate_transform_fixture.py` using OpenUSD 26.8. They
exercise all six Euler orders, pivot inverses, mirrored nonuniform scale,
quaternions and reset stacks. The reference contains column-vector matrices.
All files in this directory use the repository licence.
